# Summer Cafe Menu

여름 시즌 카페 메뉴를 기획하는 skill. 컨셉이나 기존 메뉴 목록을 받아 완성된 메뉴 세트와 실무 산출물을 만든다.

## 입력 파악

두 가지 입력 모드를 지원한다. 사용자의 요청에서 어느 쪽인지 판단한다.

1. **컨셉 모드**: 카페 컨셉·타깃·분위기만 주어진 경우 (예: "한강 근처 20대 타깃, 청량한 바다 컨셉"). 컨셉에 맞춰 메뉴를 처음부터 구성한다.
2. **기존 메뉴 모드**: 현재 판매 중인 메뉴 목록이 주어진 경우. 기존 메뉴의 가격대·스타일과 어울리는 여름 시즌 메뉴를 추가 제안한다. 기존 메뉴와 재료가 겹치는 메뉴를 우선하면 카페 입장에서 재고 부담이 적다는 점을 고려한다.

빠진 정보(메뉴 개수, 가격대, 타깃)는 묻지 말고 합리적으로 정한 뒤 결과물에 가정을 명시한다. 기본값: 메뉴 8~10개, 한국 카페 시세 기준 가격.

## 메뉴 구성 원칙

- **카테고리 균형**: 커피 베리에이션, 논커피 음료(에이드·스무디·티), 디저트를 섞는다. 여름 메뉴이므로 아이스·차가운 메뉴 중심으로 하되 전부 음료로만 채우지 않는다.
- **현실적인 가격**: 2026년 한국 카페 시세를 기준으로 한다 (아메리카노 4,500~5,500원, 에이드 6,000~7,000원, 디저트 5,000~8,000원대). 재료 원가율은 25~35%가 일반적이다.
- **만들 수 있는 레시피**: 실제 카페에서 재현 가능한 재료와 분량으로 쓴다. 구하기 어려운 재료나 전문 장비가 필요한 레시피는 피한다.
- **이름은 컨셉을 살려서**: 메뉴 이름이 카페 컨셉과 시즌 감성을 전달하는 첫 번째 수단이다. 다만 뭘 파는지 알 수 없는 이름은 피한다 (좋은 예: "블루 하와이 에이드", 나쁜 예: "여름의 꿈").

## 산출물 (4종 모두 생성)

출력 폴더 하나를 만들고 (사용자가 지정하지 않으면 `summer-menu-<카페명 또는 컨셉>/`) 아래 4개 파일을 전부 생성한다.

### 1. `menu.md` — 메뉴 문서
카테고리별로 정리한다. 각 메뉴: 이름, 한 줄 설명, 가격. 상단에 컨셉 요약과 가정(타깃, 가격대 근거)을 적는다.

### 2. `recipes.md` — 레시피 카드
메뉴마다 하나의 카드 섹션:
```markdown
## 블루 하와이 에이드
- **분량**: 1잔 (16oz)
- **재료**: 블루큐라소 시럽 30ml, 레몬즙 15ml, 탄산수 200ml, 얼음 가득, 레몬 슬라이스 1개
- **만드는 법**:
  1. 컵에 얼음을 가득 채운다
  2. 시럽과 레몬즙을 넣는다
  3. 탄산수를 붓고 가볍게 젓는다
  4. 레몬 슬라이스로 마무리
- **팁**: 시럽을 먼저 넣어야 그라데이션이 생긴다
```
디저트는 매장 제조 기준(또는 완제품 납품 기준이면 명시)으로 쓴다.

### 3. `menu-board.html` — 메뉴판
카페에 걸거나 인쇄할 수 있는 단일 HTML 파일. 외부 리소스 없이 자체 완결(인라인 CSS, 시스템 폰트 또는 웹세이프 폰트). 여름 감성의 색과 레이아웃을 컨셉에 맞게 디자인한다. A4 세로 인쇄를 고려해 `@media print`를 넣는다. 카테고리 구분, 메뉴명·설명·가격이 한눈에 읽혀야 한다. 가격은 "5,500" 형식으로 콤마를 넣는다.

### 4. `cost-sheet.xlsx` — 원가표
번들 스크립트를 사용한다. 메뉴 데이터를 JSON으로 만들어 스크립트에 넘기면 원가표 엑셀이 생성된다:

```bash
python3 <skill-path>/scripts/make_cost_sheet.py menu-data.json cost-sheet.xlsx
```

JSON 형식 (재료 원가는 1잔/1개 분량 기준 원가):
```json
{
  "cafe_name": "카페 이름",
  "items": [
    {
      "category": "에이드",
      "name": "블루 하와이 에이드",
      "price": 6500,
      "ingredients": [
        {"name": "블루큐라소 시럽 30ml", "cost": 450},
        {"name": "레몬즙 15ml", "cost": 200},
        {"name": "탄산수 200ml", "cost": 300},
        {"name": "컵·빨대·부자재", "cost": 250}
      ]
    }
  ]
}
```

스크립트가 요약 시트(메뉴별 원가·원가율·마진)와 상세 시트(재료 내역)를 만든다. 원가율이 40%를 넘는 메뉴가 있으면 가격이나 레시피를 조정한다. 컵·부자재 비용(200~300원)을 빼먹지 않는다. 스크립트 실행 후 `menu-data.json`은 지우지 말고 폴더에 같이 둔다 (나중에 수정할 때 재사용).

## 마무리

4개 파일을 모두 만든 뒤:
1. HTML 메뉴판을 열어볼 수 있게 경로를 안내한다
2. 메뉴 구성 요약(카테고리별 개수, 가격 범위, 평균 원가율)을 짧게 보고한다
3. 사용한 가정(타깃, 시세 기준)을 명시한다
