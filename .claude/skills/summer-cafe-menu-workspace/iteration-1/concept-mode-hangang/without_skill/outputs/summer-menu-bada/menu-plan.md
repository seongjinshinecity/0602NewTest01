## 1. 한강 블루라군 에이드
- 컨셉: 한강 위에 떠 있는 열대 라군. 매장 대표 포토 메뉴.
- 구성: 블루큐라소 시럽 + 라임즙 + 탄산수, 애플민트·라임 슬라이스 가니시
- 비주얼: 투명 컵 아래층 진한 블루 → 위층 옅은 하늘색 그라데이션
- 판매 포인트: "한강 배경으로 찍으면 바다처럼 나오는 음료"로 SNS 유도

## 2. 파도 크림 소다
- 컨셉: 잔 위에 하얀 파도 거품이 부서지는 모습
- 구성: 블루레몬 소다 베이스 + 우유 거품 크림 토핑 + 솔티드 크럼블
- 포인트: 크림이 소다에 번지며 파도 무늬가 생기는 연출 → 릴스용

## 3. 바다소금 크림 콜드브루
- 컨셉: 짭짤한 바닷바람. 커피 고정 수요층용 시그니처
- 구성: 콜드브루 원액 + 바다소금 휘핑크림 + 소금 플레이크
- 포인트: 단짠 밸런스, 논커피족 아닌 20대 커피 수요 흡수

## 4. 코코넛 세일링 스무디
- 컨셉: 요트 위에서 마시는 트로피컬 스무디
- 구성: 코코넛워터 + 코코넛밀크 + 파인애플 + 얼음 블렌딩, 코코넛 칩 토핑
- 포인트: 비유제품 옵션 가능(코코넛밀크만 사용), 러닝·자전거족 수분 보충 포지셔닝

## 5. 선셋 오션 에이드
- 컨셉: 한강 노을이 바다에 번지는 색 (블루→오렌지 그라데이션)
- 구성: 자몽청 + 오렌지주스 + 블루큐라소 + 탄산수
- 포인트: 블루라군과 색 대비 → "커플·친구끼리 하나씩" 세트 판매 유도

## 6. 씨글라스 젤리 티소다
- 컨셉: 해변에서 줍는 바다유리(씨글라스) 조각
- 구성: 얼그레이 콜드브루 티 + 탄산수 + 블루·민트색 한천 젤리 큐브
- 포인트: 씹는 재미(젤리 토핑), 저카페인 옵션

## 7. 파도 빙수
- 컨셉: 그릇 안에 담은 파도. 2인 공유형 디저트
- 구성: 우유얼음 + 블루멜로우 시럽 + 연유 + 코코넛 크럼블 '모래' + 화이트초코 조개 장식
- 포인트: 객단가 상승 견인, 매장 체류형(테이블) 메뉴

## 8. 조개 마들렌 세트
- 컨셉: 조개 모양 마들렌 3종 (플레인 / 솔티드카라멜 / 블루 글레이즈)
- 구성: 3개 1세트, 미니 파라솔 픽 장식
- 포인트: 음료 페어링용 사이드, 테이크아웃 선물 수요

## 운영 메모
- 그라데이션 음료는 시럽 → 얼음 → 탄산수 순서 고정, 레시피 카드로 표준화
- 블루큐라소 시럽·한천 젤리·솔티드 크럼블은 3개 메뉴 이상에서 공유 → 재고 회전 효율
- 피크 시간(주말 오후~노을)에 테이크아웃 전용 라인 분리 권장
- SNS 이벤트: 한강 배경 + 음료 사진 업로드 시 마들렌 1개 증정
