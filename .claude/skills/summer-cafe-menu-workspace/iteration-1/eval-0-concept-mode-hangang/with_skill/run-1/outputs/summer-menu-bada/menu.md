# 여름 메뉴 — 청량한 바다

## 컨셉 요약
- **위치·타깃**: 한강 근처, 20대 고객 중심
- **컨셉**: '청량한 바다' — 블루 톤 비주얼, 탄산·시트러스·코코넛 중심의 시원한 맛, 사진 찍고 싶은 그라데이션·레이어 연출
- **구성**: 총 8개 (커피 2 · 논커피 음료 4 · 디저트 2)

## 가정
- 메뉴 개수를 지정받아 8개로 구성
- 가격은 2026년 한국 카페 시세 기준 (아메리카노 4,500~5,500원대 상권 가정, 한강 인근 20대 상권 특성상 비주얼 음료는 6,000~7,000원대)
- 재료 원가율 25~35% 목표, 컵·빨대·부자재 포함
- 디저트 중 소금빵은 완제품(베이커리 납품) 기준, 파르페는 매장 제조 기준

---

## 커피

| 메뉴 | 설명 | 가격 |
|---|---|---|
| **딥블루 라떼** | 우유 위에 바닷빛 블루 코코넛 크림을 올린 아이스 라떼, 층이 살아있는 시그니처 | 6,000 |
| **파도 소금크림 아인슈페너** | 진한 콜드브루 위에 짭짤한 소금 크림이 파도 거품처럼 올라간 아인슈페너 | 6,500 |

## 논커피 음료

| 메뉴 | 설명 | 가격 |
|---|---|---|
| **블루 하와이 에이드** | 블루큐라소와 레몬, 탄산이 만드는 가장 바다다운 한 잔 | 6,500 |
| **청귤 민트 에이드** | 제주 청귤청에 민트를 더해 끝맛까지 청량한 에이드 | 6,500 |
| **코코 파도 스무디** | 코코넛+파인애플 스무디에 블루 시럽 그라데이션, 해변 칵테일 무드 | 7,000 |
| **미드나잇 오션 티** | 버터플라이피 아이스티, 레몬 시럽을 부으면 남색→보랏빛으로 변하는 색변화 티 | 5,500 |
