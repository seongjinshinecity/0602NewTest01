# 레시피 카드 — 청량한 바다

## 딥블루 라떼
- **분량**: 1잔 (16oz)
- **재료**: 에스프레소 2샷(40ml), 우유 180ml, 코코넛 시럽 15ml, 생크림 40ml, 블루큐라소 시럽 10ml, 얼음 가득
- **만드는 법**:
  1. 생크림에 블루큐라소 시럽 10ml를 넣고 살짝 걸쭉하게(반휘핑) 휘핑해 블루 크림을 만든다
  2. 컵에 얼음을 가득 채우고 코코넛 시럽과 우유를 붓는다
  3. 에스프레소를 얼음 위로 천천히 부어 층을 만든다
  4. 블루 크림을 맨 위에 얹는다
- **팁**: 크림은 흐를 듯 말 듯한 농도가 층이 가장 예쁘다. 블루 크림은 영업 전 미리 만들어 냉장 보관(당일 소진)

## 파도 소금크림 아인슈페너
- **분량**: 1잔 (12oz)
- **재료**: 콜드브루 원액 60ml, 물 100ml, 생크림 60ml, 연유 15ml, 소금 1g, 얼음 가득
- **만드는 법**:
  1. 생크림에 연유와 소금을 넣고 반휘핑한다
  2. 컵에 얼음을 채우고 콜드브루 원액과 물을 붓는다
  3. 소금 크림을 스푼으로 파도치듯 두툼하게 올린다
- **팁**: 크림 위에 소금을 한 꼬집 더 뿌리면 첫 모금의 단짠이 확실해진다

## 블루 하와이 에이드
- **분량**: 1잔 (16oz)
- **재료**: 블루큐라소 시럽 30ml, 레몬즙 15ml, 탄산수 200ml, 얼음 가득, 레몬 슬라이스 1개
- **만드는 법**:
  1. 컵에 얼음을 가득 채운다
  2. 시럽과 레몬즙을 넣는다
  3. 탄산수를 붓고 가볍게 젓는다
  4. 레몬 슬라이스로 마무리
- **팁**: 시럽을 먼저 넣어야 그라데이션이 생긴다

## 청귤 민트 에이드
- **분량**: 1잔 (16oz)
- **재료**: 청귤청 50g, 라임즙 10ml, 탄산수 200ml, 애플민트 3~4잎, 얼음 가득
- **만드는 법**:
  1. 컵 바닥에 청귤청을 넣는다
  2. 얼음을 가득 채우고 라임즙을 넣는다
  3. 탄산수를 붓고 두세 번만 젓는다
  4. 민트 잎을 손바닥으로 한 번 쳐서 향을 낸 뒤 올린다
- **팁**: 청은 끝까지 다 젓지 말고 바닥에 조금 남겨야 마실수록 진해지는 재미가 있다

## 코코 파도 스무디
- **분량**: 1잔 (16oz)
- **재료**: 코코넛 밀크 100ml, 파인애플(냉동) 120g, 바닐라 시럽 10ml, 얼음 150g, 블루큐라소 시럽 15ml
- **만드는 법**:
  1. 컵 안쪽 벽에 블루큐라소 시럽을 돌려 바른다
  2. 코코넛 밀크, 파인애플, 바닐라 시럽, 얼음을 블렌더에 갈아준다
  3. 시럽 바른 컵에 스무디를 부으면 파도 무늬 그라데이션이 생긴다
- **팁**: 시럽은 컵을 기울여 돌리며 발라야 파도 무늬가 자연스럽다

## 미드나잇 오션 티
- **분량**: 1잔 (16oz)
- **재료**: 버터플라이피 티백 1개, 뜨거운 물 100ml, 레몬 시럽 20ml(별도 미니 저그), 탄산수 100ml, 얼음 가득
- **만드는 법**:
  1. 티백을 뜨거운 물 100ml에 5분 우려 진한 남색 베이스를 만든 뒤 식힌다
  2. 컵에 얼음을 채우고 베이스와 탄산수를 붓는다
  3. 레몬 시럽은 미니 저그에 따로 내어, 손님이 직접 부어 색이 변하는 걸 보게 한다
- **팁**: 색변화(남색→보라)가 이 메뉴의 핵심. 서빙 때 "부어보세요" 한마디가 SNS 업로드로 이어진다

## 바다 파르페 컵
- **분량**: 1개 (유리컵 350ml) — 매장 제조
- **재료**: 블루 젤리(사이다 200ml+블루큐라소 10ml+판젤라틴 3g) 80g, 플레인 요거트 100g, 생크림 30ml, 꿀 10g, 그래놀라 30g, 코코넛 칩 5g
- **만드는 법**:
  1. 사이다·블루큐라소·불린 젤라틴을 섞어 굳힌 뒤 깍둑썰기한다 (전날 준비, 냉장 2일 보관)
  2. 요거트에 생크림과 꿀을 섞어 크림을 만든다
  3. 유리컵에 그래놀라(모래) → 요거트 크림 → 블루 젤리(바다) 순으로 쌓는다
  4. 코코넛 칩을 뿌려 파도 거품을 표현한다
- **팁**: 층 경계가 선명해야 '바다 단면'이 산다. 크림은 짤주머니로 넣으면 벽이 지저분해지지 않는다

## 소금빵 아이스크림 샌드
- **분량**: 1개 — 소금빵은 완제품(베이커리 납품) 기준
- **재료**: 소금빵 1개(납품), 바닐라 아이스크림 80g(스쿱 1개), 꿀 5g
- **만드는 법**:
  1. 소금빵을 오븐에 2분 데워 겉을 바삭하게 한다
  2. 옆면을 갈라 바닐라 아이스크림 한 스쿱을 넣는다
  3. 꿀을 가볍게 뿌려 낸다
- **팁**: 빵이 따뜻할 때 바로 내야 겉바속촉+차가운 아이스크림 대비가 산다. 주문 즉시 제조
