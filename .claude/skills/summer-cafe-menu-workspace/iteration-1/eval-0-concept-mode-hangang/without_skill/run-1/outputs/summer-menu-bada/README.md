# summer-menu-bada — 청량한 바다 여름 메뉴

한강 근처 · 20대 타깃 카페의 여름 시즌 메뉴 8종(음료 6 + 디저트 2) 기획 산출물.

## 파일 구성
| 파일 | 내용 |
|------|------|
| `menu-plan.md` | 메뉴 기획서 — 컨셉, 라인업 8종, 가격·원가율, 메뉴별 판매 포인트, 운영 메모 |
| `recipes.md` | 매장 표준 레시피 카드 8종 + 영업 전 배치 프렙 리스트 |
| `menu-board.html` | 바다 그라데이션 테마 HTML 메뉴판 (브라우저에서 열기) |
| `menu-board-screenshot.png` | 메뉴판 렌더링 스크린샷 |
| `cost-sheet.csv` | 메뉴별 판매가·예상 원가·원가율 표 |
| `command-input.txt` | 이 폴더를 만든 입력 명령어 |

1. 한강 블루라군 에이드 6,500원 (시그니처)
2. 파도 크림 소다 6,800원 (시그니처)
3. 바다소금 크림 콜드브루 6,000원

6. 씨글라스 젤리 티소다 6,300원
7. 파도 빙수 12,000원 (시그니처, 2인)
8. 조개 마들렌 세트 5,500원 (3개입)
