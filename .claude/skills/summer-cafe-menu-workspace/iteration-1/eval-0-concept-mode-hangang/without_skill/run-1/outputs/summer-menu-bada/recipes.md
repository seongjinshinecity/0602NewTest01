# 청량한 바다 — 레시피 카드 (매장 표준)

기준: 톨 사이즈(음료 473ml 컵), 얼음은 각얼음 기준. 제조 시간은 숙련 기준.

---

## 1. 한강 블루라군 에이드 — 6,500원
- 재료: 블루큐라소 시럽 30ml, 라임즙 15ml, 설탕시럽 10ml, 탄산수 250ml, 얼음 가득, 애플민트 1줄기, 라임 슬라이스 1개
- 제조 순서
  1. 컵에 블루큐라소 시럽 + 라임즙 + 설탕시럽을 먼저 붓는다
  2. 얼음을 컵 끝까지 채운다
  3. 탄산수를 얼음 위로 천천히 부어 그라데이션을 만든다 (젓지 않는다)
  4. 애플민트·라임 슬라이스 가니시
- 제조 시간: 1분 30초 / 주의: 서빙 직전 제조(그라데이션 유지)

## 2. 파도 크림 소다 — 6,800원
- 재료: 블루레몬 시럽 25ml, 레몬즙 10ml, 탄산수 230ml, 우유 100ml + 휘핑크림 30ml(폼), 솔티드 크럼블 5g, 얼음
- 제조 순서
  1. 시럽 + 레몬즙 + 얼음 + 탄산수로 소다 베이스를 만든다
  2. 우유와 휘핑크림을 프로더로 가볍게 폼을 낸다
  3. 폼을 스푼 등으로 받쳐 소다 위에 얹는다 (파도 거품 연출)
  4. 크럼블을 한쪽에만 뿌려 '해변 모래' 연출
- 제조 시간: 2분 30초

## 3. 바다소금 크림 콜드브루 — 6,000원
- 재료: 콜드브루 원액 80ml, 물 120ml, 얼음, 휘핑크림 60ml + 우유 30ml + 바다소금 1g(크림), 소금 플레이크 약간
- 제조 순서
  1. 휘핑크림 + 우유 + 소금을 70% 휘핑해 소금크림을 만든다 (영업 전 배치 제조 가능, 냉장 4시간)
  2. 컵에 얼음 → 물 → 콜드브루 원액 순서로 붓는다
  3. 소금크림을 1.5cm 두께로 올리고 소금 플레이크 마무리
- 제조 시간: 1분 30초

## 4. 코코넛 세일링 스무디 — 7,000원
- 재료: 코코넛워터 150ml, 코코넛밀크 80ml, 냉동 파인애플 120g, 설탕시럽 15ml, 얼음 100g, 코코넛 칩 5g
- 제조 순서
  1. 얼음·냉동 파인애플·액체 재료를 블렌더에 넣고 30초 블렌딩
  2. 컵에 붓고 코코넛 칩 토핑
- 제조 시간: 2분 / 옵션: 유제품 완전 배제 가능(휘핑 미사용)

## 5. 선셋 오션 에이드 — 6,500원
- 재료: 자몽청 40g, 오렌지주스 60ml, 블루큐라소 시럽 15ml, 탄산수 200ml, 얼음, 자몽 슬라이스
- 제조 순서
  1. 컵에 자몽청 + 오렌지주스를 넣는다 (아래층 주황)
  2. 얼음을 채우고 탄산수를 붓는다
  3. 블루큐라소 시럽을 얼음 위에서 천천히 흘려 위층 파랑을 만든다
  4. 자몽 슬라이스 가니시
- 제조 시간: 2분 / 주의: 블루는 마지막, 젓지 않고 서빙

## 6. 씨글라스 젤리 티소다 — 6,300원
- 재료: 얼그레이 콜드브루 티 150ml, 탄산수 120ml, 설탕시럽 15ml, 블루·민트 한천 젤리 큐브 60g, 얼음
- 젤리 배치 제조(영업 전): 한천가루 4g + 물 500ml + 설탕 40g 끓인 뒤 반은 블루큐라소 10ml, 반은 민트시럽 10ml로 착색 → 굳혀서 1.5cm 큐브 컷, 냉장 2일 사용
- 제조 순서
  1. 컵 바닥에 젤리 큐브를 담는다
  2. 얼음 → 얼그레이 티 → 탄산수 순서로 붓는다
  3. 시럽으로 당도 조절, 굵은 빨대 제공
- 제조 시간: 1분 30초

## 7. 파도 빙수 — 12,000원 (2인)
- 재료: 우유얼음 400g, 블루멜로우 시럽 40ml, 연유 50ml, 코코넛 크럼블 30g, 화이트초코 조개 2개, 휘핑크림 40ml
- 제조 순서
  1. 우유얼음을 갈아 그릇에 산 모양으로 쌓는다
  2. 한쪽 면에만 블루멜로우 시럽을 부어 '파도', 반대쪽에 크럼블로 '모래사장'을 만든다
  3. 연유를 전체에 두르고 휘핑크림 + 화이트초코 조개 장식
- 제조 시간: 4분 / 주의: 시럽·크럼블 경계를 섞지 않는 것이 비주얼 핵심

## 8. 조개 마들렌 세트 — 5,500원 (3개입)
- 구성: 플레인 1 + 솔티드카라멜 1 + 블루 글레이즈 1
- 반죽(배치, 약 24개): 박력분 200g, 버터 200g, 설탕 180g, 달걀 4개, 꿀 20g, 베이킹파우더 6g / 냉장 휴지 1시간 / 175°C 12분
- 베리에이션
  - 솔티드카라멜: 굽기 전 반죽에 카라멜소스 5g 인젝션, 소금 플레이크
  - 블루 글레이즈: 슈가파우더 100g + 우유 20ml + 블루큐라소 5ml 글레이즈에 반만 디핑
- 서빙: 3개 세트 박스 + 미니 파라솔 픽 / 유통: 실온 2일
