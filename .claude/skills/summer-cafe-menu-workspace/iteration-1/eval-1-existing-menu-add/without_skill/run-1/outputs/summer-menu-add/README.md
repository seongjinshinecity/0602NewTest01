# summer-menu-add — 여름 시즌 메뉴 6종 추가

기존 메뉴(아메리카노 4,500 / 카페라떼 5,000 / 바닐라라떼 5,500 / 크루아상 4,800)에
어울리는 여름 시즌 신메뉴 6종을 기획한 산출물.

## 신메뉴 요약

| 메뉴 | 구분 | 가격 |
|---|---|---|
| 콜드브루 토닉 | 커피 | 5,500원 |
| 아이스 크림 콜드브루 | 커피 | 5,800원 |
| 제주 청귤 에이드 | 논커피 | 5,500원 |
| 수박 주스 | 논커피 | 5,800원 |
| 망고 코코넛 스무디 | 논커피 | 6,000원 |
| 레몬 커드 크루아상 | 베이커리 | 5,800원 |

## 파일 구성

| 파일 | 내용 |
|---|---|
| `summer-menu.md` | 신메뉴 기획서 — 선정 이유, 가격 전략, 전체 가격표, 운영 포인트 |
| `recipes.md` | 6종 레시피 카드 (재료·분량·만드는 법·포인트) + 공통 준비물 |
| `menu-board.html` | 매장용 메뉴판 (브라우저로 열기, 인쇄용 스타일 포함) |
| `menu-board-screenshot.png` | 메뉴판 렌더링 스크린샷 |
| `cost-sheet.xlsx` | 원가표 — 시트1 메뉴별 원가·마진·원가율(수식), 시트2 재료 상세 |
| `command-input.txt` | 이 산출물을 만든 입력 명령어 |

## 사용법

- 메뉴판: `menu-board.html`을 브라우저로 열면 됨. 인쇄 시 배경·그림자가 자동 제거됨.
- 원가표: 납품가 확정 후 시트1의 "재료 원가" 열(C열)만 수정하면 총 원가·마진·원가율이 자동 재계산됨.
