# 여름 신메뉴 레시피 카드 (6종)

모든 음료는 아이스 전용, 16oz(약 470ml) 컵 기준.

---

## 1. 아이스 크림 콜드브루 — 5,800원

**재료**
- 콜드브루 원액 60ml
- 물 120ml
- 얼음 가득
- 바닐라 크림: 생크림 60ml + 우유 20ml + 바닐라시럽 10ml + 설탕 5g

**만드는 법**
1. 크림 재료를 휘핑기(또는 거품기)로 45~50% 정도만 휘핑한다. 흐르는 농도가 핵심.
2. 컵에 얼음 → 물 → 콜드브루 원액 순으로 붓는다.
3. 바스푼 등에 대고 크림을 천천히 올려 층을 만든다.

**포인트**: 크림을 과하게 휘핑하면 층이 안 예쁘게 나온다. 제공 시 "젓지 말고 드셔보세요" 안내.

---

## 2. 콜드브루 토닉 — 5,500원

**재료**
- 콜드브루 원액 60ml
- 토닉워터 200ml
- 라임 슬라이스 1개(또는 라임즙 5ml)
- 얼음 가득

**만드는 법**
1. 컵에 얼음을 가득 채우고 토닉워터를 붓는다.
2. 라임 슬라이스를 넣는다.
3. 콜드브루 원액을 얼음 위로 천천히 부어 층을 만든다.

**포인트**: 토닉을 먼저, 커피를 나중에. 순서가 바뀌면 층이 사라지고 탄산이 죽는다.

---

## 3. 제주 청귤 에이드 — 5,500원

**재료**
- 청귤청 50g
- 탄산수 250ml
- 얼음 가득
- 애플민트 1줄기, 청귤(또는 레몬) 슬라이스 1개

**만드는 법**
1. 컵에 청귤청을 넣는다.
2. 얼음을 가득 채우고 탄산수를 붓는다.
3. 가볍게 2~3회만 저어주고 민트와 슬라이스로 마무리.

**포인트**: 많이 저으면 탄산이 빠진다. 청은 바닥에 살짝 남는 편이 시각적으로 좋다.

---

## 4. 수박 주스 — 5,800원

**재료**
- 수박 과육 350g (씨 제거)
- 얼음 5~6개
- (선택) 소금 아주 소량 — 단맛 보정용

**만드는 법**
1. 수박 과육을 블렌더에 넣고 10~15초, 짧게 간다.
2. 얼음 몇 개와 함께 한 번 더 3초. 얼음은 온도용, 갈아버리지 않는다.
3. 무가당 그대로 제공. 수박 조각 하나를 컵 테두리에 장식.

**포인트**: 오래 갈면 거품이 많아지고 분리가 빨라진다. 주문 즉시 제조, 미리 갈아두지 않는다.

---

## 5. 망고 코코넛 스무디 — 6,000원

**재료**
- 냉동망고 150g
- 코코넛밀크 100ml
- 플레인 요거트 50g
- 설탕 시럽 15ml (망고 당도에 따라 가감)
- 얼음 4~5개

**만드는 법**
1. 모든 재료를 블렌더에 넣고 30초간 곱게 간다.
2. 너무 되면 코코넛밀크 10~20ml 추가.
3. 컵에 담고 코코넛 칩(있으면)을 토핑.

**포인트**: 냉동망고를 5분 정도 살짝 해동하면 블렌더 부하가 줄고 식감이 부드럽다.

---

## 6. 레몬 커드 크루아상 — 5,800원

**재료**
- 크루아상 1개 (기존 메뉴 재고)
- 레몬 커드 40g
- 슈가파우더 약간
- 레몬 제스트 약간

**만드는 법**
1. 크루아상을 옆으로 반 가른다 (완전히 자르지 않고 주머니 형태).
2. 레몬 커드를 안쪽에 짜 넣는다.
3. 윗면에 슈가파우더를 뿌리고 레몬 제스트로 마무리.
4. 주문 후 제조. 미리 넣어두면 눅눅해진다.

**포인트**: 레몬 커드는 시판 제품 사용 가능. 직접 만들 경우 레몬즙 100ml + 설탕 100g + 달걀 2개 + 버터 50g을 중탕으로 걸쭉하게 (냉장 5일 보관).
