# 여름 시즌 메뉴 레시피 카드

## 카페 토닉
- **분량**: 1잔 (16oz)
- **재료**: 에스프레소 2샷(원두 18g), 토닉워터 150ml, 레몬 슬라이스 1개, 얼음 가득
- **만드는 법**:
  1. 컵에 얼음을 가득 채우고 토닉워터를 붓는다
  2. 에스프레소 2샷을 추출한다
  3. 얼음 위로 에스프레소를 천천히 부어 층을 만든다
  4. 레몬 슬라이스를 컵 안에 꽂아 마무리
- **팁**: 에스프레소를 얼음에 맞고 흐르게 부으면 층이 깨지지 않는다. 저어서 제공하지 말고 손님이 섞어 마시게 안내한다

## 돌체 아이스라떼
- **분량**: 1잔 (16oz)
- **재료**: 에스프레소 2샷(원두 18g), 우유 150ml, 연유 30g, 얼음 가득
- **만드는 법**:
  1. 컵 바닥에 연유 30g을 넣는다
  2. 얼음을 가득 채우고 우유를 붓는다
  3. 에스프레소 2샷을 위에 천천히 올린다
- **팁**: 연유-우유-커피 3층이 핵심. 스푼 대신 빨대로 저어 마시게 안내하면 비주얼이 오래 간다

## 청포도 에이드
- **분량**: 1잔 (16oz)
- **재료**: 청포도청 60g, 레몬즙 10ml, 탄산수 200ml, 얼음 가득, 애플민트 1줄기
- **만드는 법**:
  1. 컵에 청포도청과 레몬즙을 넣는다
  2. 얼음을 가득 채운다
  3. 탄산수를 붓고 가볍게 두 번만 젓는다
  4. 애플민트를 올려 마무리
- **팁**: 많이 저으면 탄산이 죽는다. 청에 든 청포도 알갱이가 위로 뜨도록 마지막에 한 스푼 얹으면 좋다

## 망고 요거트 스무디
- **분량**: 1잔 (16oz)
- **재료**: 냉동 망고 100g, 요거트 파우더 30g, 우유 100ml, 얼음 120g
- **만드는 법**:
  1. 블렌더에 냉동 망고, 요거트 파우더, 우유, 얼음을 넣는다
  2. 덩어리가 없어질 때까지 30~40초 간다
  3. 컵에 붓고 망고 큐브 2~3개를 올려 마무리 (선택)
- **팁**: 너무 오래 갈면 묽어진다. 되직하게 나와야 스무디 느낌이 산다

## 아이스크림 크루아상
- **분량**: 1개
- **재료**: 크루아상 1개(기존 판매 제품), 바닐라 아이스크림 90g(1스쿱 반), 메이플시럽 10g, 슈가파우더 약간
- **만드는 법**:
  1. 크루아상을 오븐(또는 에어프라이어) 180도에서 2~3분 데운다
  2. 가로로 반 갈라 접시에 올린다
  3. 바닐라 아이스크림을 가운데에 올린다
  4. 메이플시럽을 뿌리고 슈가파우더로 마무리
- **팁**: 크루아상이 따뜻할 때 바로 내야 아이스크림 대비가 산다. 매장 내 취식 전용으로 운영 권장

## 레몬 파운드 케이크
- **분량**: 1조각 (약 90g)
- **재료**: 레몬 파운드 케이크 1조각 — **완제품 납품 기준** (베이커리 업체 발주)
- **만드는 법**:
  1. 냉장 보관된 케이크를 주문 시 접시에 올린다
  2. 레몬 제스트 또는 슈가파우더를 약간 뿌려 마무리 (선택)
- **팁**: 여름철에는 실온 방치하지 말고 냉장 보관, 유통기한 라벨 확인. 아이스 음료와 세트 구성하기 좋다
