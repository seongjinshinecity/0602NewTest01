# 여름 시즌 메뉴 추가 제안 (6종)

## 컨셉 요약

에스프레소 기반 클래식 메뉴(아메리카노 4,500 / 카페라떼 5,000 / 바닐라라떼 5,500 / 크루아상 4,800)를 판매 중인 동네 카페에, 기존 가격대·스타일과 자연스럽게 이어지는 여름 시즌 메뉴 6종을 추가한다.

**구성 방향**
- 기존 재고(에스프레소 원두, 우유, 바닐라 시럽, 크루아상)를 최대한 재활용해 신규 발주 부담을 줄였다. 완전 신규 재료는 토닉워터, 청포도청, 냉동망고, 요거트 파우더, 바닐라 아이스크림, 연유 정도다.
- 커피 베리에이션 2종 + 논커피 음료 2종 + 디저트 2종으로 카테고리 균형을 맞췄다.

**가정 (사용자 미지정 항목)**
- 타깃: 기존 메뉴 가격대로 볼 때 20~40대 일반 상권 손님 기준.
- 가격: 2026년 한국 카페 시세 기준. 시즌 메뉴는 기존 메뉴보다 500~1,300원 높은 5,500~6,800원대로 책정 (에이드·스무디 6,000~7,000원 시세 반영).
- 재료 원가율 목표 25~35% 이내.

---

## 커피 베리에이션

| 메뉴 | 설명 | 가격 |
|---|---|---|
| **카페 토닉** | 토닉워터 위에 에스프레소를 얹은 청량한 스파클링 커피. 레몬 슬라이스로 마무리 | 5,500 |
| **돌체 아이스라떼** | 연유의 부드러운 단맛에 에스프레소를 층으로 올린 시원한 라떼 | 5,800 |

## 논커피 음료

| 메뉴 | 설명 | 가격 |
|---|---|---|
| **청포도 에이드** | 알갱이 씹히는 청포도청에 탄산수를 부은 여름 대표 에이드, 애플민트 토핑 | 6,000 |
| **망고 요거트 스무디** | 냉동 망고와 요거트를 갈아 만든 진하고 새콤한 스무디 | 6,800 |

## 디저트

| 메뉴 | 설명 | 가격 |
|---|---|---|
| **아이스크림 크루아상** | 판매 중인 크루아상을 따뜻하게 데워 바닐라 아이스크림을 올린 시즌 디저트 | 6,800 |
| **레몬 파운드 케이크** | 상큼한 레몬 글레이즈 파운드 케이크 1조각 (완제품 납품) | 5,500 |

---

## 기존 메뉴와의 재료 연결

| 신메뉴 | 재사용하는 기존 재료 |
|---|---|
| 카페 토닉 | 에스프레소 원두 |
| 돌체 아이스라떼 | 에스프레소 원두, 우유 |
| 아이스크림 크루아상 | 크루아상 (기존 판매 제품 그대로) |
| 망고 요거트 스무디 | 우유 |

신규 발주 재료: 토닉워터, 연유, 청포도청, 애플민트, 냉동망고, 요거트 파우더, 바닐라 아이스크림, 메이플시럽, 레몬(슬라이스용), 레몬 파운드 케이크(완제품).
