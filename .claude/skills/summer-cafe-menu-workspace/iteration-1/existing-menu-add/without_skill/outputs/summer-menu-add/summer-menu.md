# 여름 시즌 메뉴 추가 제안

## 기존 메뉴

| 메뉴 | 가격 |
|---|---|
| 아메리카노 | 4,500원 |
| 카페라떼 | 5,000원 |
| 바닐라라떼 | 5,500원 |
| 크루아상 | 4,800원 |

기존 라인업은 에스프레소 베이스 3종 + 베이커리 1종. 가격대는 4,500~5,500원.
여름 신메뉴는 이 가격대에서 크게 벗어나지 않는 **5,500~6,000원** 구간으로 잡아,
"시즌 메뉴 = 기본 메뉴보다 500원~1,000원 프리미엄" 구조를 만든다.

## 여름 시즌 신메뉴 6종

### 커피 베이스 (기존 고객 확장)

**1. 아이스 크림 콜드브루 — 5,800원**
- 콜드브루 위에 바닐라 크림을 올린 아인슈페너 스타일.
- 아메리카노 고객의 "한 단계 위" 선택지. 바닐라라떼(5,500원)와 재료(바닐라시럽·우유)를 공유해 재고 부담이 없다.

**2. 콜드브루 토닉 — 5,500원**
- 토닉워터 + 콜드브루 + 라임. 탄산이 있는 커피로, 더운 날 아메리카노 대체재.
- 콜드브루 원액은 1번 메뉴와 공유.

### 논커피 (신규 고객 유입)

**3. 제주 청귤 에이드 — 5,500원**
- 청귤청 + 탄산수 + 애플민트. 여름 에이드의 기본기. 청귤청은 병 제품으로 관리가 쉽다.

**4. 수박 주스 — 5,800원**
- 생수박 착즙, 무가당. 재료가 수박 하나라 오퍼레이션이 단순하고 계절감이 가장 확실하다.
- 판매 기간을 '수박 시즌 한정'으로 명시해 희소성을 준다.

**5. 망고 코코넛 스무디 — 6,000원**
- 냉동망고 + 코코넛밀크 + 요거트. 시즌 최고가 메뉴로 객단가를 끌어올리는 앵커.

### 디저트 (크루아상 활용)

**6. 레몬 커드 크루아상 — 5,800원**
- 기존 크루아상(4,800원)에 레몬 커드 + 슈가파우더를 더한 여름 버전.
- 신규 발주 없이 기존 베이커리 재고로 만드는 시즌 메뉴. 크루아상 대비 +1,000원.

## 운영 포인트

- **재료 공유**: 콜드브루 원액(1·2번), 바닐라시럽(기존 바닐라라떼·1번), 크루아상(기존·6번) — 신규 발주 품목을 최소화.
- **세트 제안**: "서머 세트" = 여름 음료 아무거나 + 레몬 커드 크루아상 500원 할인.
- **판매 기간**: 6월 중순 ~ 9월 초. 수박 주스는 수박 단가에 따라 조기 종료 가능.
- **원가율**: 전 메뉴 원가율 22~32% 구간(상세는 cost-sheet.xlsx 참고). 카페 음료 권장 원가율 35% 이내.
