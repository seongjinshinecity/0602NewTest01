**개념 — AI와 Context의 이해**
- 🚩개념 **`AI`** — AI는 신이 아니라 "Context 연산기계". Transformer 학습=귀납법, Thinking(추론) 모드=연역법 비유
- 🚩개념 **`Context`** — Context 만들기 3가지(직접 주입/AI가 스스로 찾기/Rules 고정) + Text·Image Context, MCP, CLI. 팁: AI는 GUI보다 텍스트 기반 CLI를 훨씬 잘 다룸

**개념 — 채팅 vs 에디터 vs 에이전트** (같은 결과물을 3가지 방식으로)
- 🚩개념 **채팅 vs 에디터 vs 에이전트** — 채팅(지식 Q&A, ChatGPT류)/에디터(작업 보조, Cursor류)/에이전트(스스로 계획·실행, 터미널·브라우저·파일시스템 직접 제어, Claude Code류)를 4개 축 비교표로
- 🚩개념 채팅으로 본인소개 웹사이트 만들기
- 🚩개념 에디터로 본인소개 웹사이트 만들기 (Cursor)
- 🚩개념 에이전트로 본인소개 웹사이트 만들기 (클로드 코드)

**도구 셋업 & 에이전트 실습**
- 🚩튜토리얼 **클로드 코드 둘러보기 / + 커서 셋업** — Cursor 초기 설정: settings.json으로 .md 마크다운 프리뷰 기본화, Cmd+K 터미널 에디터 단축키
- 🚩개념 클로드 코드 에이전트 & 스킬
- 🚩에이전트 **레시피 에이전트** — 냉장고 재료/요청 → 15분 이내 초간단 레시피를 `recipes/`에 md 저장 + 나노바나나(Gemini 이미지 API) 직접 호출로 썸네일 PNG 생성. `GEMINI_API_KEY` 없어도 레시피 md는 생성
- 🚩에이전트 **K-Drama 일기 에이전트** — 일기를 K-드라마 장면으로 변환해 `diary/diary-kdrama-{날짜}.md`로 저장(원본 인용→드라마 제목→장면→BGM/연출). 존재하지 않는 작품·배우 지어내기 금지 규칙

**퀘스트(과제)** *(공통: 기본 10pt~올클리어 25pt · 기한 월 23:59 · 에이전트 대화 스크린샷 필수)*

**웹앱의 구조 (프론트엔드 기초)**
- 🚩개념 앱의 구조 (Web Application) *(임베드 다이어그램)*
- 🚩개념 **Browser: HTML, CSS, JS** — HTML=구조(뼈대)/CSS=꾸미기/JS=변화(상태·움직임). 버튼 클릭으로 이모지 박스가 춤추는 예제를 Cursor로 직접 작성
- 🚩에이전트 **React Agent (SPA: index.html)** — CDN React 18+Tailwind+Babel standalone으로 빌드 도구 없이 단일 index.html 웹앱을 만드는 single-react-dev 에이전트. 컴포넌트→라우터→레이아웃→페이지→App 순 구성, API URL 하드코딩 금지. 팁: CDN 버전 고정 필수, @babel/standalone은 8.x가 깨져서 7.25.9 핀
- 🚩튜토리얼 **개발자도구(Elements/Console/Network)로 디버깅** — 화면 문제=Elements, JS 에러=Console, 데이터 문제=Network. "재현→해당 탭 확인→정상/이상 비교→원인 소거" 루틴. 팁: Disable cache·Preserve log·Throttling

**앱의 유형 이해**
- 🚩개념 **앱의 10가지 유형** — 핵심 기능 6종(계산기·저장소·중계기·감지/제어기·변환기·AI) + 인프라 4종(자동화기·연결기·문지기·거래기). 실제 앱은 "핵심 1~2개 + 인프라 조합"
- 🚩개념 **앱의 유형: 계산기 (Calculation)** — 입력을 공식에 넣어 **없던 새 정보**를 만드는 결정론적 앱 (BMI·D-day·운세). 저장·외부 API 없이 바로 답이 나오면 계산기
- 🚩개념 **앱의 유형: 변환기 (Transform)** — 같은 정보를 다른 형태로 (QR·마크다운 미리보기·단위 변환). 구분법: "원본 복원 가능하면 변환, 새 값이 나오면 계산"

**도전 과제 (고블린)**
- 🚩고블린 **[Calculation] 나이 계산기** — 생년월일 입력 → 만 나이 출력 (input·button·이벤트 첫 체험)
- 🚩고블린 **[Calculation] D-day 카운터** — 목표 날짜까지 남은 일수 계산 (Date 객체·실시간 업데이트)
- 🚩고블린 **[Transform] 색상 팔레트 생성기** — HEX 코드(컬러피커) 입력으로 밝은/어두운 변형 5색 생성, "같은 정보 다른 형태" 체험

**버전 관리 (Git)**
- 🚩개념 **Git & GitHub** — `git --version` 설치 확인 + `gh auth login` GitHub CLI 인증
- 🚩튜토리얼 Git 으로 Commit 하기 (SavePoint)
- 🚩튜토리얼 GitHub 에 Push 하기

**퀘스트(과제)**

- 🚩퀘스트 **[Calculation] 세금 계산기** — 종합소득세·부가가치세 중 원하는 세금 계산기 하나

- 🚩퀘스트 **[Design] 내 명함 만들기** — 처음 만난 사람이 5초 만에 "뭐 하는 사람인지" 알 수 있는 명함 디자인. 표준 사이즈 90×54mm, 직함/태그라인 한 줄 + 핵심 정보 5가지 이내, 앞면+뒷면(QR·슬로건·포트폴리오 링크). 기본 10pt + 에이전트 활용 5pt + 창의성 5pt + 공유 보너스 5pt. 팁: 폰트 2개 이내·컬러 2~3색, 강조는 딱 1곳에만
- 🚩퀘스트 **[Design] 카페 신메뉴 포스터 만들기** — 신메뉴 이름·가격·한줄설명 + "사야 하는 이유" 1가지 정의 후 1080×1350(인스타 4:5) 또는 A4 세로 포스터로. 메인 카피 3~7단어, 신메뉴 비주얼이 포스터 50% 이상, 인스타 스토리·단톡방 실제 게시까지가 미션. 기본 10pt + 에이전트 활용 5pt + 창의성 5pt + 반응 보너스(좋아요·댓글 3개+) 5pt
- 🚩퀘스트 **[Design] 카페 메뉴판 만들기** — 카페 이름·분위기·타겟손님 컨셉 정의 → 컬러 3색 이내·폰트 2개 이내로 카테고리 3개+·메뉴 8개+·시그니처 메뉴 1개를 A4 세로 또는 1080×1350 메뉴판으로. 기본 10pt + 에이전트 활용 5pt + 창의성 5pt + 공유 보너스 5pt. 팁: 좋아하는 카페 메뉴판 3개를 레퍼런스로 옆에 두고 시작

**파이널 퀘스트 (택1 추정 — 개인 프로젝트 or 가이드 캡스톤)**
- 🚩퀘스트 **[Final] 개인 프로젝트 v1 완성 — 끝까지 밀어붙이기 (디자인 + 핵심 기능 + 배포 + 발표용 썸네일 1장)** — 6주차 `[Planning] 기획서 2종(MISSION/DEV)`을 완료한 상태가 전제. 메인+핵심 화면 2개 이상 디자인 + MISSION 중 핵심 기능 1개를 끝까지 동작하도록 + Vercel 배포 + 발표용 썸네일(1920×1080, 프로젝트명+한줄소개+대표비주얼) 1장. 기본 10pt + 에이전트 활용 5pt + 완성도(디자인 일관성+데모영상+회고) 5pt + 실사용 인증(본인 외 1명+) 5pt. 팁: 기능 10개 반쪽보다 1개 완성이 가치있음, 배포 먼저 다듬기 나중에
- 🚩퀘스트 **[Final] 당근마켓 클론** — 개인 프로젝트 대신(또는 대체로) 선택 가능한 가이드형 마지막 퀘스트. Auth(가입+동네설정)+상품등록(이미지 3장+RLS)+목록/검색+1:1 채팅(Polling)+마이페이지+Vercel 배포를 전부 통합, "그동안 만든 퀘스트들의 합성"으로 프레이밍. 기본 10pt + 채팅 구현 5pt + 에이전트 활용 5pt + 본인 외 1명 이상 가입·채팅 인증 5pt. 팁: 채팅은 가장 까다로우니 마지막에, Part1~3만 굴러가도 80% 완성, 5~6주차 커뮤니티 앱 코드를 출발점으로

### 🧩 기초반에서 다루는 앱 카테고리 정리

| 카테고리 | 설명 | 대표 결과물 |

| **Transform (변환기)** | 입력을 다른 형태로 변환 | 색상 팔레트·짤·QR·PDF 생성기 |
| **Network (API 사용)** | 외부 API를 불러오는 앱 | 포켓몬 도감·날씨앱·NASA·코인 시세 |
| **Server (백엔드)** | 직접 서버/API 제작 | 나만의 API, Single Server |
| **Server + AI** | 서버 + AI 결합 | AI 별명 생성기, AI 꿈해몽 앱 |
| **Server + DB** | 서버 + 데이터베이스(Supabase) | 게시판, 밸런스 게임, 냉장고 재료 관리앱, 연봉 비교, 가계부 |
| **Auth (인증)** | 로그인·회원가입·권한 | 커뮤니티 앱, 쇼핑몰(결제 제외), 관리자 대시보드 |
| **MCP / Skill** | MCP 연동·재사용 스킬·실무 문서 자동화 | Notion/크롬 MCP, 레시피 스킬, 엑셀·PPT 보고서 |
| **Context** | 나만의 맥락(.md) 기반 앱 | 나를 설명하는 Q&A 앱/에이전트, `my_cafe.md` |
| **File (업로드)** | 이미지 업로드 백엔드 (ImageKit) | 쇼핑몰 상품 이미지 업로드 (관리자) |
| **Payment (결제)** | 한국형 결제 연동 (TossPayments) | 결제 붙인 쇼핑몰, 100원 테스트 결제 |
| **Planning (기획)** | 개인 프로젝트 기획 문서 | MISSION.md / DEV.md 2종 (2026-07-14: AUDIENCES 제외로 변경 확인) |
| **Design (디자인)** | 사이즈 고정형 이미지 디자인 실습 | 프로필 카드·인스타 광고 카드·YouTube 썸네일·명함·카페 메뉴판/포스터 |
