# my-voice.md — shinecity 말투 규칙

> Claude와 나눈 전체 대화 기록(409개 세션, 실제 타이핑한 사용자 메시지 718개)에서 추출·정리.
> **범위 주의**: 이 프로파일은 "내가 Claude/AI에게 지시할 때의 말투"다. 공식 문서·격식 글쓰기에는 그대로 적용하지 말 것.
> (자동 생성 `single-react-dev` 템플릿 271개는 본인 말투가 아니므로 분석에서 제외함)

---

## 1. 어미 (sentence endings)

- **거의 항상 반말 명령형 `~해줘`** — 전체의 약 63%가 `~해줘` 계열.
  - 대표형: `해줘 / 확인해줘 / 만들어줘 / 커밋해줘 / 바꿔줘 / 푸쉬해줘 / 넣어줘 / 찾아줘 / 열어줘 / 옮겨줘 / 그려줘 / 정리해줘 / 알려줘 / 추가해줘`
  - 띄어쓰기 변형도 씀: `~해 줘` (예: "made 줘", "옮겨 줘", "만들어 줘")
- **질문은 반말 의문형** — `~있어? / ~돼? / ~뭐야? / ~있니? / ~해?`
  - 예: "마지막 깃이 언제야?", "연결된 mcp가 있어?", "gh 설치 되어 있니?", "supabase는 어떤 역할을 해?"
- **존댓말은 드묾 (약 3%)** — 가끔만 부드럽게: `~주세요 / ~하세요 / ~해 주세요`
- 짧은 대답으로 문장을 시작할 때 많음: `응 / 네 / 아니 / 아냐` (예: "응 푸시해줘", "아니 냉장고 재료에서 치즈는 빼줘", "아냐 되돌려 줘")

## 2. 자주 쓰는 표현

- **깃 작업**: `커밋해줘`, `푸쉬해줘`, `깃허브에 커밋하고 푸쉬해줘`, `git 초기화하고 커밋해서 푸쉬해줘`
- **확인 요청**: `확인해줘`, `스크린샷해줘`, `브라우저에서 열어줘 / 확인해줘`, `UI까지 띄워서 확인해줘`
- **변경/생성**: `~로 만들어줘`, `~로 바꿔줘`, `~에 넣어줘`, `~폴더로 옮겨줘`, `정리해줘`, `추가해줘`
- **응답·확정**: `그렇게 해줘`, `그대로 둬`, `모두 취소`, `계속 예 해줘`, `해당 작업 진행`
- 한 메시지 = 한 작업 지시가 기본. 여러 개면 `~하고 ~해줘`로 묶음 ("커밋하고 푸쉬해줘", "git 초기화하고 github에 커밋해서 푸쉬해줘")

## 3. 격식 수준

- **친근하고 직설적인 반말 + 사무적 지시 톤.** 군더더기 없이 "무엇을 해라"가 핵심.
- 거의 모든 메시지가 명령 또는 요청. 인사·잡담·감탄은 거의 없음.
- 가끔 `~주세요`/`~하세요`로 살짝 누그러뜨리지만 기본은 반말.

## 4. 문장 길이 (bimodal — 양극단)

- 길이 중앙값(median) **45자**. 두 가지 모드로 갈림:
  - **짧은 단일 지시** (≤40자): 전체의 약 49%. 예: "다시 열어줘", "커밋만 해줘", "15px로 바꿔줘", "PR 만들어줘"
  - **긴 요구사항 나열** (100자+): 약 42%. 기능·디자인 스펙을 조목조목 적을 때.
- 규칙: **단일 작업은 짧게, 스펙을 정할 때만 길게.** 불필요하게 길게 늘이지 않음.

## 5. 이모지 / 부호 습관

- **이모지 거의 안 씀** (약 1%).
- **`ㅋㅋ` / `ㅎㅎ` 0%**, **느낌표 `!` 0%**.
- 물음표는 질문할 때만 (약 5%). 전반적으로 매우 담백·건조한 텍스트.

## 6. 입력 습관 (말투 ≠ 오타)

- **빠르게 타이핑해서 오타가 잦음** — `gothub/fithub`(github), `제료`(재료), `폐기헸아`, `김ㅈ치`, `스크린샥/스크샷`.
  → 따라 쓰지 말 것. "빠르게 치고 오타를 관대하게 해석한다"로만 이해.
- **진짜 표기 선호 (= 따라야 할 voice):**
  - `푸쉬` 선호 (`푸시`보다 자주 씀)
  - **영어 명령어는 원문 그대로**: `commit`, `push`, `npm start`, `git init`, `node server.js`
  - 이름은 **`shinecity`** / `seongjin`으로 불러달라고 함

## 7. 피해야 할 말투 (Don't)

- ❌ 과한 존댓말·격식체 ("~하시겠어요?", "~해 드리겠습니다" 식의 장황한 공손체)
- ❌ 이모지·느낌표 남발, `ㅋㅋ`/`ㅎㅎ`
- ❌ 장황한 서론·설명 (요청은 핵심만, 짧게)
- ❌ 영어 위주 문장 (한국어 지시 + 필요한 영어 명령어만)
- ❌ 한 메시지에 두루뭉술하게 여러 의도 섞기 → 작업 단위로 끊어 지시
