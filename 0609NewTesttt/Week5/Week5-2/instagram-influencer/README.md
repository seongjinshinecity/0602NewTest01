# 📸 인스타 인플루언서 찾기 (instagram-influencer) — 배치3 [홍보, 20점]

우리 카페(데일리브루)와 결이 맞는 인스타 인플루언서를 **인게이지먼트율 + 타겟 적합도**로 발굴해 Top5 추천 + 컨택 초안까지. 팔로워 수보다 **실제 반응률**이 핵심.

## 구성
- `target.md` — 타겟 인플루언서 정의(지역/연령/감성, my_cafe.md 근거). 마이크로/나노(팔로워 1천~3만) 우선, ER≥3%.
- `methodology.md` — 점수화 방법(인게이지먼트율 공식 + 적합도 100점 표 + 반자동 절차 + 안전 경계).
- `engagement.py` — 인게이지먼트율 + 등급 계산 보조 도구.
- `influencers.template.md` — 실데이터 입력용 **빈 템플릿**.
- `influencers.example.md` — **가상(@demo_*) 워크플로우 시연**.
- `dm-drafts.md` — Top3 컨택 DM 초안 3종(사람이 직접 발송).
- `assist_browse.py` — 후보를 한 명씩 열어 보여주는 **보기 보조**(수집·발송 자동화 안 함).

## ⚠️ 라이브 실행의 경계 (중요)
이 퀘스트의 실제 발굴은 **사용자 본인 인스타 로그인 세션**에서만 가능하다. 그래서 이 폴더는:
- ✅ 방법론 + 계산 도구 + 가상 예시 + 컨택 초안을 **완성해서 제공**한다.
- ❌ **사용자의 인스타 계정에 로그인하지 않는다**(비밀번호 입력 금지) — 가이드 자체가 "자동화는 발굴·열람까지, 컨택은 사람이 직접"으로 제한하고, 대량 스크래핑·자동 DM은 계정 정지 위험이라 하지 않는다.
- ❌ **실존 계정에 가짜 수치를 붙이지 않는다.** `influencers.example.md`의 모든 핸들은 `@demo_*` 가상이며, 실데이터는 사용자가 `influencers.template.md`에 직접 채운다.

## 어떻게 검증했나 (이번 세션)
- `engagement.py`를 실제로 돌려 계산 로직을 확인: 팔로워 8,200 / ♥540 / 💬31 → **ER 6.96% '우수'**, 팔로워 21,000 / ♥410 / 💬22 → **ER 2.06% '보통'**.
- `influencers.example.md`의 점수는 이 실제 로직 + `methodology.md` 점수표로 산출했다. 시연 포인트: 팔로워 1위(@demo_food_mega_05, 5만)가 반응률 0.25%로 **걸러지고**, 반응·적합도 높은 후보가 위로 올라간다 = "팔로워 수 함정" 회피.

## 실제로 돌리려면 (사용자)
1. 크롬에서 **본인 인스타 로그인**(비밀번호는 Claude에 입력 X).
2. `#성수동카페 #성수디저트` 등 해시태그에서 후보를 눈으로 수집, 최근 9~12개 ♥/💬 평균 기록.
3. `python3 engagement.py <팔로워> <♥> <💬>` 로 율 계산 → 적합도 점수 → `influencers.template.md` 채우기.
4. Top3에 `dm-drafts.md`로 **직접** DM.

## 출처
방법론·도구·가상 예시·DM 초안은 Week5-1 참고본에서 이식, **engagement.py 계산은 이번 세션에 실행 검증**했다.
