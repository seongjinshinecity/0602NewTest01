## 🚩퀘스트 [Network] 책 검색 & 독서 위시리스트 위젯

**난이도:** 3주차 수준 · ⭐⭐⭐
**예상 소요:** 2~3시간

**🎯 미션**
Google Books API를 fetch로 호출해 책을 검색하고, 마음에 드는 책을 "읽고 싶어요" 목록에 저장하는 단일 페이지 위젯을 완성하라.

**📋 필수 요구사항 (제출 기준)**
- [ ] 앱 UI를 직접 제작해 단일 `index.html` 파일 하나로 동작 (별도 서버·빌드 도구 없이 브라우저에서 열리면 됨)
- [ ] 검색창에 제목 또는 저자를 입력하면 Google Books API(`https://www.googleapis.com/books/v1/volumes?q=...`)를 fetch로 호출함
- [ ] 검색 결과를 카드 형태로 렌더링: 표지 이미지, 제목, 저자, 출판연도 포함
- [ ] 각 카드에 "읽고 싶어요" 버튼이 있으며, 클릭 시 해당 책이 위시리스트 섹션에 추가됨
- [ ] 위시리스트는 `localStorage`에 저장되어 새로고침 후에도 유지됨
- [ ] 위시리스트에서 개별 항목을 삭제할 수 있음
- [ ] 검색 중 로딩 표시, 결과 없음 메시지 등 최소한의 상태 처리가 있음
- [ ] 실행 화면 스크린샷을 찍어 `README.md`에 이미지로 첨부 (검색 결과 + 위시리스트가 함께 보이게)
- [ ] 앱 폴더에 `index.html`·`README.md`(+스크린샷)를 함께 GitHub에 푸쉬

**✅ 완료 조건 (Acceptance Criteria)**
- "파친코" 검색 → 관련 도서 카드 1개 이상 화면에 표시됨
- 카드의 "읽고 싶어요" 클릭 → 하단(또는 사이드) 위시리스트 섹션에 해당 책이 나타남
- 페이지 새로고침 → 위시리스트에 추가한 책이 그대로 남아 있음
- 위시리스트 항목의 삭제 버튼 → 목록에서 제거되고 localStorage에서도 사라짐
- `README.md`를 GitHub에서 열면 실행 화면 스크린샷이 정상적으로 렌더링됨

**💡 힌트**
- Google Books API는 API 키 없이도 하루 수백 건까지 무료 호출 가능. 단, 쿼터 초과 시 429 에러가 나므로 응답 상태 코드를 반드시 체크할 것.
- `fetch(url).then(res => res.json())` 체인 후 `items` 배열을 순회하면 됨. 표지 이미지는 `volumeInfo.imageLinks?.thumbnail` 경로에 있는데, 없는 경우도 있으니 옵셔널 체이닝과 대체 이미지를 준비할 것.
- localStorage는 문자열만 저장 가능. 객체를 저장·불러올 때 `JSON.stringify` / `JSON.parse`를 빠뜨리지 않도록 주의.
- 중복 저장 방지가 필요하다면 책 고유 ID(`item.id`)를 활용하는 것을 고려해볼 것.
- 엔터 키 검색은 `form` 태그의 `submit` 이벤트 또는 `keydown` 이벤트로 처리하면 UX가 자연스러움.

**🧩 고블린 (선택 심화)**
- 위시리스트에 "읽음 완료" 체크 토글을 추가하고, 완료된 책은 시각적으로 구분하여 표시하라.
- 검색 결과를 최대 표시 수(예: 10개) 조절하는 슬라이더나 드롭다운을 추가하고, `maxResults` 파라미터를 API 요청에 반영하라.

**📤 제출 가이드**

- `README.md`에는 앱 소개 한 줄 + 실행 화면 스크린샷(검색 결과 + 위시리스트) + (선택) GitHub Pages 배포 URL 포함
