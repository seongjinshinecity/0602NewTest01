| **_goal/** | 단기 목표들 — **목표 하나 = 폴더 하나** (plan/problems/progress 3파일 + 산출물). 끝나면 판정 적고 닫음 | `README.md` (스코어보드 ← **평소엔 이걸 본다**) · `01-b2b-validation/` 🥇 · `02-popup-pricing/` · `03-marketing-channel/` (influencers.md 포함) · `04-location-scouting/` |

**흐름**: signals(들어옴) → daily(논의·결정) → goal(해당 목표 폴더에 반영, 산출물도 그 안에) → mission(구조적이면 승격)

**판별 규칙**: 세상 상태의 기록(관찰)이면 signals, 내가 만든 실행 자산이면 그걸 만든 goal 폴더 안에.
