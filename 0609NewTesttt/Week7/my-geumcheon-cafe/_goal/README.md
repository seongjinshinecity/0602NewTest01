## 국면 공통

- 예산: 검증 4단계 합계 **~80만** (1.32억 쓰기 전 확인 — [_mission/feasibility.md](../_mission/feasibility.md) §5)

- 공통 제약: 사장(나)의 가용 시간 미확정 — 주간 캘린더 먼저 잡을 것

## 🤖 에이전트 (목표당 1명 — 스킬을 알아서 호출하는 전담 담당자)

> 상태: 전부 📝 설계만. 구조: **에이전트 = 목표의 담당자** — 자기 폴더(plan/problems/progress)를 컨텍스트로 갖고,
> 필요한 스킬을 스스로 골라 호출하고, 결과를 자기 progress.md에 기록한다. 사장(나)은 스코어보드만 본다.
> 공통 규칙: ① 실행 후 `_daily/`에 한 줄 ② 막히면 자기 problems.md에 등록 ③ 고정 규칙(가격·계약 금지)은 변경 불가, 위반 감지 시 보고만

| 에이전트 (가칭) | 담당 | 역할 (한 줄) | 알아서 호출하는 스킬 | 부르는 순간 |
|---|---|---|---|---|
| **`b2b-manager`** | 🥇 01 | B2B 영업 매니저 — 리스트업→키트 제작→방문 기록→의향서 8곳 관문 추적을 끝까지 책임 | `b2b-prospects` → `b2b-outreach-kit` → `b2b-visit-log` (단계 자동 판단) | "B2B 진행시켜" · 방문 다녀온 뒤 결과 보고할 때 |
| **`popup-runner`** | 🥈 02 | 팝업 운영자 — 장소 섭외 문안·준비 체크리스트·회차 기록·관문 판정까지 팝업 1회분 전체 | `popup-log` (+ 섭외 콜드컨택 문안은 직접 작성) | "팝업 준비하자" · 팝업 끝나고 숫자 부를 때 |
| **`channel-keeper`** | 🥉 03 | 채널 운영자 — 주간 릴스 기획 발행, 인플루언서 컨택 전 생존 확인 강제, 사전주문 재사용률 추적 | `reels-plan` (주간) · `influencer-check` (컨택 직전 자동) + 전역 ig-ad-gen·comfyui | "이번 주 릴스" · "OO한테 DM 보내자" (→ check 먼저) |
| **`location-scout`** | — 04 | 매물 스카우트 — 주간 모니터링·후보 축적·답사 메모. **계약 직전까지만** (계약 금지 가드레일 내장) | `listing-watch` (주간) | "매물 봐줘" · 주 1회 정기 |

**에이전트 없이 남기는 것**: 스코어보드·게이트 판정(`cafe-gate-check`)과 daily 마감(`cafe-daily`)은 특정 목표 소속이 아니라 **메인 세션(사장 대화)의 몫** — 목표 간 우선순위 조정은 담당자가 아니라 사장이 한다.
