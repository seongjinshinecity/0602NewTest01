# 문제 (mission-level) — 구조적 리스크

> 국면이 지나도 사라지지 않는 문제들. 단기 문제는 각 목표 폴더의 `_goal/<목표>/problems.md`.

1. **B2B는 가설이지 계약된 매출이 아니다** — 이 창업 전체의 성립 조건인데 아직 검증 0. (→ Phase 0)
2. **권리금 5,000만 = 최대 리스크 자산** — 실패 시 회수 불확실. 무권리 매물 발굴이 최선의 방어 (회수 17.6→9.1개월).
3. **주말 공백** — 오피스 상권 숙명. 단축 영업 + 아울렛 테이크아웃으로 방어하되, 손익 모델은 영업일 26일 기준.
4. **저가 체인의 가격 지배력** — 정면 가격 경쟁 불가. '시간(줄 안 섬)+팀 소비' 포지션에서 이탈하면 진다.
5. **B2B 집중 리스크** — 대형 거래처 2곳이 매출 15%면 이탈 시 즉시 BEP 아래 → 거래처 10곳+ 분산 필수.
6. **미계상 비용** — 사장 4대보험·감가상각·연말 오피스 공동(空洞) 시즌 → 계약 전 세무사 검토.
