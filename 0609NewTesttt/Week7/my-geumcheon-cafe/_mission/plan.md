# 계획 (mission-level, 장기) — 창업 로드맵

> 성립 조건: **B2B로 오피스 평균의 2배(월 1,169만+)를 넘기는 것.** ([feasibility.md](feasibility.md) §4)
> 각 Phase는 통과 기준을 넘어야만 다음으로 — 계약(1.32억)은 Phase 0 통과 후에만.

| Phase | 기간(예상) | 내용 | 통과 기준 |
|---|---|---|---|
| **0. 수요 검증** ← 지금 | ~8주 | B2B 의향서·팝업·가격·채널 4단계 (~80만) | **의향서 8곳+** 포함 3개+ 통과 |
| 1. 계약·구축 | ~3개월 | 매물 계약(무권리 우선), 인테리어·장비, 사전주문 채널 | 총투자 ≤1.32억 (무권리 시 8,200만) |
| 2. 오픈·안착 | ~6개월 | 7:30 오픈 운영, B2B 거래처 10곳+ 분산 | 월매출 1,169만+ (생존선) |
| 3. 안정화 | ~12개월 | B2B 매출 비중 27%+, 커피패스 구독 확대 | 월매출 1,600만+ (회수 17.6개월 트랙) |

## Phase 0 실패 시 분기
- 의향서 8곳 미달 → B2B 가설 폐기 → **입지 하향(무권리·이면) 또는 컨셉 회귀** — 그대로 진행 금지
