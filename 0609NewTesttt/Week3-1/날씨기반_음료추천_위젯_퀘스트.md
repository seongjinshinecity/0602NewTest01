## 🚩퀘스트 [Network] 날씨 기반 "오늘의 음료" 추천 위젯

**난이도:** 3주차 수준 · ⭐⭐⭐
**예상 소요:** 2~4시간

**🎯 미션**
사용자가 도시(또는 현재 위치)를 입력하면 외부 날씨 API로 실시간 날씨를 불러와서, 기온·날씨 상태에 맞는 "오늘의 음료"를 추천해 주는 단일 `index.html` 웹앱을 만든다. 카페 사장님 화면에 띄워둘 수 있는 위젯 형태로.

**📋 필수 요구사항 (제출 기준)**
- [ ] 도시 이름 입력창 + "추천받기" 버튼이 있다
- [ ] 외부 날씨 API(OpenWeatherMap 등)를 `fetch`로 호출해 실시간 데이터를 가져온다
- [ ] 현재 기온(℃)과 날씨 상태(맑음/비/눈/흐림 등)를 화면에 표시한다
- [ ] 기온·상태에 따라 음료를 1개 이상 추천한다 (예: 28℃ 이상 → 아이스 아메리카노 / 5℃ 이하 → 따뜻한 라떼 / 비 → 핫초코)
- [ ] 추천 이유를 한 줄로 같이 보여준다 ("기온 31℃, 더운 날엔 시원한 콜드브루")
- [ ] API 키는 코드에 그대로 박지 말고 입력창이나 변수 상단 한 곳에 모아둔다 (제출 시 키 노출 주의)
- [ ] 앱 UI를 직접 제작해 단일 `index.html`로 동작한다 (빌드 도구 없이 브라우저에서 바로 열려야 함)
- [ ] 실행 화면 스크린샷(더운 날 / 추운 날 또는 비 오는 날 — 분기가 다르게 동작하는 게 보이게)을 찍어 `README.md`에 이미지로 첨부
- [ ] 앱 폴더에 `index.html`·`README.md`(+스크린샷)를 함께 GitHub에 푸쉬

**✅ 완료 조건 (Acceptance Criteria)**
- "서울" 입력 → 실제 서울의 현재 기온/상태가 뜨고, 그에 맞는 음료가 추천된다
- 존재하지 않는 도시("asdf") 입력 → 에러 메시지를 보여주고 앱이 멈추지 않는다
- 더운 날 / 추운 날 / 비 오는 날 응답이 서로 다른 추천을 낸다 (분기 로직이 실제로 작동)
- `README.md`를 GitHub에서 열면 실행 화면 스크린샷이 정상적으로 렌더링됨

**💡 힌트**
- 날씨 API는 OpenWeatherMap의 `Current Weather Data` 엔드포인트가 무료·간단함. 가입 후 API 키 발급 → `?q=Seoul&appid=KEY&units=metric&lang=kr`
- `fetch(url).then(res => res.json())` 흐름. 응답 JSON에서 `main.temp`, `weather[0].main` / `weather[0].description`을 꺼내 쓴다
- 추천 로직은 if/else 또는 룩업 테이블로. 먼저 기온 구간을 나누고, 그 위에 "비/눈" 같은 상태 예외를 덮어쓰는 순서로 짜면 깔끔하다
- API 호출 실패(잘못된 도시, 네트워크 오류)는 `try/catch` 또는 `.catch()`로 잡아서 사용자에게 메시지로 보여줄 것 — 콘솔에만 찍고 끝내지 말기
- 키 노출이 걱정되면 화면에서 키를 입력받아 쓰는 방식으로 시작해도 된다

**🧩 고블린 (선택 심화)**
- 브라우저 Geolocation API로 "현재 위치" 버튼을 만들어 도시 입력 없이 내 위치 날씨로 추천
- 추천 음료에 어울리는 이미지/이모지와 간단한 카드 UI 추가
- 최근 조회한 도시 3개를 `localStorage`에 저장해 빠르게 다시 보기
