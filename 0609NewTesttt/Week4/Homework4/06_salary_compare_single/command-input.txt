# 이 앱을 만들 때 입력한 명령어

기존 풀스택 앱 "연봉/지출 비교"를 서버 없는 단일 index.html(CDN React + Tailwind) 버전으로 새로 만들어줘.

생성 위치(절대경로): /Users/hwangseongjin/Downloads/0602NewTest01/0609NewTesttt/Week4/Homework4/06_salary_compare_single/index.html

먼저 원본을 읽어서 디자인 톤(💸 연봉/지출 비교, 이모지·색감)과 기능을 최대한 맞춰줘:
- 원본 프론트: .../06_salary_compare/index.html
- 원본 서버/DB 로직 참고: 같은 폴더의 server.js, db.js, README.md

요구사항(프론트 단독이므로 백엔드 없이 구현):
1. 사용자가 본인의 연봉/월지출(또는 항목별 지출)을 익명 입력한다.
2. 백엔드 DB 집계 대신, 앱에 내장한 샘플 분포 데이터셋(현실적인 연봉/지출 구간별 가상 표본 수십~수백 개를 코드에 하드코딩)을 기준으로 내 위치를 비교한다: 백분위(percentile), 평균 대비, 분포 히스토그램/막대 차트로 시각화.
3. 내가 제출한 기록은 localStorage에 저장해서 재방문 시 유지하고, 내 입력도 표본에 합산해 보여준다(브라우저 로컬 한정임을 UI에 작게 명시).
4. 한국어 UI, 모바일 반응형, 깔끔한 카드/차트. 차트는 CDN(Recharts 또는 Chart.js 등)로.
5. 완전히 자체완결형 단일 파일. 빌드 도구·번들러 없이 브라우저에서 바로 열려야 함.

완성하면 어떤 기능을 어떻게 구현했는지(특히 샘플 분포·localStorage 처리) 요약해서 알려줘.
