# 📣 [홍보] 우리 카페 띄워줄 인스타 인플루언서 찾기 (20점 퀘스트)

로그인된 실제 인스타그램을 브라우저로 자동 탐색해 데일리브루(성수동 디저트 카페)와 결이 맞는
인플루언서 후보 5명을 발굴하고, 인게이지먼트율 기준 Top3 + DM 초안까지 작성.

## 산출물

| 파일 | 내용 |
|---|---|
| `influencers.md` | 타겟 정의 + **Top5 표**(팔로워/지표/ER/적합도) + Top3 추천 + **DM 초안 3건** + 안전 수칙 기록 |
| `screenshots/01-hashtag-explore.png` | `#성수카페` 해시태그 탐색 화면 (실 브라우저) |
| `screenshots/02-candidate-profile-daisy.png` | 후보 프로필 열람 화면 |
| `screenshots/03-candidate-post-junny.png` | 게시물 지표(좋아요·댓글) 확인 화면 |

## 진행 방식 (채점 기준 대응)

- **발굴(6pt)**: `#성수카페` 게시물 6건 → 작성자·댓글 계정 추적 → 후보 6명 검토, 5명 확정 (스크린샷 증빙)
- **분석(6pt)**: 팔로워가 아니라 **실측 좋아요·댓글 기반 ER** 비교 — 2.2만 계정(65%)부터 1.3천 마이크로(7.8%)까지. 좋아요 비공개 계정은 측정 불가로 정직 표기
- **추천·적합도(4pt)**: my_cafe.md 타겟(20~30대 여성·디저트·카공)과 연결한 한 줄 이유
- **컨택 메시지(2pt)**: 계정별 맞춤 DM 3건 (무료 체험 + 게시물 1건 제안)
- **안전 수칙**: 열람만, 상호작용 0건, DM 발송은 사람이 직접

## 재현

크롬(claude-in-chrome)에서 본인 로그인 후 해시태그 URL 탐색 → 게시물 작성자 수집 → 프로필별 팔로워·최근 게시물 지표 확인 → ER 계산.
