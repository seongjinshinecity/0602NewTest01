## Q1. 우리 카페에 신메뉴 뭐 추가할까?

### [Before — 컨텍스트 없음]
계절성 음료(과일 에이드·콜드브루 변형·진한 라떼), 트렌드 재료(말차·흑임자 라떼, 제로슈거, 디카페인), 디저트는 소금빵·크로플·바스크 치즈케이크 등 "검증된 아이템" 추천. 기존 재료·장비 재활용과 1~2개씩 테스트 조언.
→ **어느 카페에나 하는 말.** 우리 가게가 이미 치즈케이크·크로플 맛집인 것도, 주방이 좁은 것도 모른다.

### [After — 내 카페 파트너]
- **실행 쿼리**: 메뉴별 판매·매출 합계, 리뷰 평점 분포, 리뷰 전문 조회
- **데이터 근거**:
  - 디저트 매출 1위 **치즈케이크 205개 · 1,332,500원**, 2위 크로플 168개 · 1,008,000원
  - 리뷰 7건 중 **"치즈케이크 품절" 언급 2건** (둘 다 주말) — 수요가 공급 초과
  - 초코쿠키는 수량 최다(216개)지만 단가 3,000원이라 매출 648,000원에 그침
- **답변(제약 반영)**:
  1. **치즈케이크 시즌 변형 1종** — 같은 반죽·같은 오븐 스케줄에서 토핑만 바꿔 단가 5,500~6,500원대. 주방 협소·인력 2명 제약 안에서 품절 수요를 흡수
  2. **청 베이스 에이드 1종** — 자몽에이드 호평(7/4, 5점) 기반. 청은 미리 담가두면 알바 혼자 조리 가능, 설비 투자 0
  3. 저단가 초코쿠키는 신메뉴 대신 **세트 구성용**으로 전환

## Q2. 평일 낮 매출을 어떻게 올릴까?

### [Before — 컨텍스트 없음]
오후 2~5시 해피아워(세트 할인·사이즈업), 노트북 좌석 정비, 오피스 단체주문·배달, 평일 스탬프 2배, SNS 노출.
→ 일반론. 우리 카페 평일이 실제로 뭐가 약한지(커피? 디저트?) 모른 채 나열.

### [After — 내 카페 파트너]
- **실행 쿼리**: `EXTRACT(DOW FROM date)` 로 평일/주말 일평균 비교, 카테고리별 평일/주말 비교
- **데이터 근거**:
  - 평일 일평균 **701,000원** vs 주말 **803,875원** (하루 약 102,875원 격차)
  - 격차의 원인은 **디저트**(198,300 vs 251,375원)와 **음료**(89,300 vs 141,750원). **커피는 평일 413,400원 ≈ 주말 410,750원으로 이미 동일**
  - 리뷰: 평일 카공 호평 2건, **월요일 점심 "줄 길고 회전 느림" 3점 리뷰 1건**
- **답변(제약 반영)**:
  1. **평일 한정 '커피+디저트 세트'** — 커피는 이미 팔리니 디저트를 붙여 객단가↑. 직접 굽는 구조라 마진 여유, 추가 인력·설비 0
  2. **월요일 점심 회전 개선** — 3점 리뷰가 정확히 지적한 문제. 11~14시 테이크아웃용 '아메리카노+쿠키' 선포장 조합으로 인력 2명으로도 줄 빼기
  - 데이터 한계도 정직하게 명시: 일 단위 DB라 '낮 시간대'는 분리 불가 → 시간대 기록을 모으면 정밀해짐

## 핵심 차이 요약

| | Before (일반 AI) | After (cafe-partner) |
|---|---|---|
| 근거 | 상식·트렌드 | 실행한 SQL 결과 수치 + 리뷰 원문 |
| 신메뉴 | 말차·소금빵 등 유행 나열 | 매출 1위 시그니처의 저부하 변형 + 품절 리뷰 근거 |
| 제약 | 무시 | 좌석 24석·인력 2명·주방 협소·예산 반영, 위반 제안 배제 |
| 진단 | "평일 낮이 약하다" 가정 | 커피는 이미 주말 수준, **디저트·음료가 빈 칸**임을 특정 |
| 한계 고지 | 없음 | 시간대 컬럼 부재를 명시하고 데이터 수집 제안 |

> 💡 **운영에 바로 쓸 사례 (보너스)**: "월요일 점심 테이크아웃 선포장" — 3점 리뷰(회전 느림)와 평일 커피 매출 데이터가 결합된, 비용 0원짜리 실행안.
