# AUDIENCES.md — 카페 사장님 대시보드

> `MISSION.md`의 타겟("데이터 볼 시간이 없는 소규모 카페 사장님 한 명")을 실제로 어디서 만나고, 어떻게 첫 사용자로 데려올지 정리.

## 1. 타겟 페르소나

**분석할 시간이 없어 감으로 운영하는 1인·2인 카페 사장님.**
포스기·인스타·날씨 앱·리뷰 알림을 마감 후에 하나씩 열어보며 하루를 조각조각 맞추는 사람 — `research.md`에서 확인한 경쟁 서비스 유저 불만("기능이 너무 많아 뭘 봐야 할지 모르겠다", "리포트는 나오는데 그래서 뭘 하라는 건지", "네이버 순위 관리하다 하루 다 감")이 곧 이 페르소나의 니즈다. **"요약해서 하나만 시켜줘."**

- 규모: 좌석 30석 이하, 직원 0~2명
- 도구: 포스기 기본 리포트 + 개인 감각. 캐시노트·Square 같은 올인원 툴은 "무거워서" 안 쓰거나 방치
- 의사결정 시점: 마감 후 또는 다음 날 아침, 짧은 틈

## 2. 어디에 있는가 (채널)

| 채널 | 왜 여기인가 | 접근 방법 |
|---|---|---|
| 네이버 카페 "카페사장님모임" 등 소상공인 커뮤니티 | 포스기·매출·운영 고민을 스스로 글로 올리는 곳 — 페인포인트가 이미 텍스트로 존재 | 검색으로 관련 글 파악 → 댓글로 자연스러운 소통, 직접 홍보 금지(커뮤니티 규칙) |
| 카카오톡 오픈채팅방 (동네·업종별 사장님방) | 실시간 질문·답변, 지역 밀착 | 성수동 인근 방 참여 관찰 후 니즈 확인 |
| 인스타그램 카페 사장님 계정 (개인 카페 브랜드 계정 운영자) | 본인 카페 홍보하면서 동시에 "관리 도구"에도 관심 있는 얼리어답터층 | `../influencer-research`에서 이미 확보한 로컬 카페 네트워크 활용 — 사장님끼리의 입소문 |
| 성수동 인근 오프라인 카페 사장님 (직접 대면) | 데일리브루 사장님 본인이 이미 접근 가능한 가장 가까운 잠재 유저 | 옆 카페 사장님에게 프로토타입 직접 보여주고 피드백 받기 — 가장 빠르고 정직한 검증 |
| 소상공인 지원 기관 커뮤니티 (예비창업자 대상 X, 운영 중인 사장님 대상) | 이미 도구 도입에 익숙, 무료 베타 테스터 모집 창구 | 베타 테스터 공고 형태로 접근 |

## 3. 첫 10명 확보 전략

1. **본인 카페부터 실사용** — 데일리브루 사장님(나)이 2주간 매일 아침 사용, MISSION.md 성공 지표(주 5회, 30초 이내) 스스로 검증
2. **성수동 인근 카페 3~5곳 직접 방문 시연** — 프로토타입(`../boss-dashboard`) 화면을 태블릿/폰으로 보여주고 즉석 피드백. 콜드 아웃리치보다 전환율 높음(같은 업종·같은 동네·무료)
3. **베타 테스터 5명 모집** — 네이버 카페/오픈채팅방에 "무료 베타 테스터 모집" 형태로 짧게 공지(홍보 아님, 참여 요청). 대가: 평생 무료 이용
4. **입소문 유도 문구** — Tagline *"A morning briefing for solo café owners."*를 그대로 후킹 메시지로 사용, "당신 대신 데이터를 조각조각 맞춰봤습니다"

## 4. 하지 않을 것

- 유료 광고 집행 (베타 단계에서 예산 낭비)
- 전국 단위 무차별 DM (계정 정지 위험 + 타겟 희석 — `influencer-research`의 안전 수칙과 동일한 원칙 적용)
- 다른 업종(식당·소매) 확장 — MISSION.md Anti-Scope와 동일하게 카페 사장님에 집중

## 연결 고리

경쟁사 유저 불만(`research.md`) → 페르소나 정의(위 1번) → 채널(2번) → 첫 10명(3번) → `MISSION.md` 성공 지표(주 5회 사용)로 검증.
